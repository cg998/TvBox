# tvbox

自持 TVBox 源接口（影视 + 动漫，无直播）。自己捣鼓 使用。

## 文件说明

| 文件 | 作用 |
|---|---|
| `tv.json` | 接口文件，电视端"配置地址"填它 |
| `test_tv.py` | 接口自测工具，改完接口后跑一遍验证站点是否存活 |

## 使用

电视端配置地址填（最终稳定地址，见加速部署后）：

```
https://你的域名/tv.json
```

## 如何测试

```bash
python test_tv.py          # 默认测 tv.json，关键词：斗罗大陆/海贼王/熊出没
python test_tv.py tv.json 海贼王 熊出没   # 自定义关键词
```

## 如何更新站点

1. 编辑 `tv.json`，增删 `sites` 数组里的站点。
2. 跑 `python test_tv.py` 验证。
3. `git commit` + `git push`，加速端自动生效（缓存约 5 分钟）。
