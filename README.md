# TvBox 自持源接口

自维护的 TVBox/FongMi 影视源接口，供父母家 TCL 电视使用。GitHub Actions 自动维护，接口地址不变，电视端零操作。

- 客户端：**蜂蜜影视**（FongMi 系，`com.fongmi.android.tv`）
- 站点：9 个自用直连 CMS 源 + 每周自动补充的直连源 + 23 个秒播源（明文 jar 自托管，非加密、国内可加载）

## 电视端配置地址

蜂蜜影视 → 设置 → 点播 → 配置地址，填入：

```
https://tvbox-202610-1503022424.cos.ap-guangzhou.myqcloud.com/my_interface.json
```

备用地址（主地址失效时用，仅直连源可用）：

```
https://cdn.jsdelivr.net/gh/cg998/TvBox@main/dist/my_interface.json
```

## 站点构成

| 类别 | 数量 | 说明 |
|---|---|---|
| 自用直连源 | 9 | 量子（默认首页）/ 非凡 / 天堂 / 360 / 火狐 / 百度 / 索尼… 见 `my_sites.json` |
| 自动补充直连源 | 若干 | 每周从 tvbox.org 筛出，去重后并入 |
| 秒播源 | 23 | 儿童 3 / 影视 8 / 短剧 6 / 体育 4 / 戏曲·养生·预告 |

秒播源取自上游**明文 jar**（`qist/tvbox`），由 `build_spiders.py` 按白名单裁剪家庭向站点；jar 镜像到自有 COS，接口 `spider` 指向 COS。**不加密、国内可直连**，因此不再受制于别人的加密 jar。

## 自动维护

| 任务 | 频率 | 说明 |
|---|---|---|
| 构建秒播源包 | 每周日 09:20 | 重拉上游 jar + 接口 → 校验未加密 → 按白名单裁剪 → 产出源包 |
| 每周全量筛选 | 每周日 09:20 | 从 tvbox.org 官方合并接口筛新直连源，去重后并入 |
| 每日健康检查 | 每天 05:20 | 挂了的源降级到末尾，连续挂 3 天剔除；保证首页源存活。**自用源（`my_sites.json`）只体检、不降级、不剔除**——体检跑在境外节点，避免误删国内精选源 |
| 部署到 COS | 随以上执行 | 镜像 jar 到 COS、重写接口地址、上传接口。**jar 每日刷新，站点清单每周刷新** |

## 调整秒播站点

改 `config.json` 的 `spider_pack.allow_classes`（白名单，**书写顺序 = 优先级**，超出 `max_sites` 时靠后的被截断），增删类名即可；`deny_classes` 为强制排除。改完触发一次「每周全量筛选」。

- 上游 jar 一旦被改成加密版，本环节会**自动停用**并退回纯直连接口，不影响电视使用。
- 想看每个类名对应的真实站点，可运行 `python build_spiders.py config.json`，产出文件里 `meta.kept` 即实际收录清单。

## 手动换血

GitHub 仓库 → Actions →「每周全量筛选影视源」→ Run workflow。
